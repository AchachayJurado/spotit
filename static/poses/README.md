# Reference Poses

Place your pose reference images in this directory. The images should be:
- Clear, well-lit photos of people performing distinct poses
- In JPG or PNG format
- Show the full body
- Have a person clearly visible against the background
- Ideally with the person facing the camera

Example poses could include:
- T-pose
- Tree pose (yoga)
- Warrior pose
- Star jumps
- Various dance moves

The game will automatically load all .jpg and .png files from this directory.
